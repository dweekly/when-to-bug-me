# Bug Me

A chief of staff for people who run fleets of agents: it brings forward only the decisions that need the person, asks why, and turns the reason into standing guidance every agent follows.

This repo holds the working prototype for an Anthropic Labs take-home. **Status:** under construction; see `docs/BUILD-PLAN.md` (fresh as of 2026-10-09) for the plan, stages and acceptance commands.

Everything shown in the prototype (the person, the company, the agents and their questions) is synthetic.
